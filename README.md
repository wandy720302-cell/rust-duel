# RUST DUEL

rust 風格的 1v1 網頁射擊小遊戲：兩個裸男、一張小地圖，兩種玩法：

- **對決**：一開始就有 AK，先殺 5 次的贏
- **生存**：只有一顆石頭，自己挖礦、打鐵桶找零件、做槍、蓋房子，肚子餓了去雪地打北極熊烤肉，30 分鐘內擊殺多的贏

純前端（three.js + PeerJS/WebRTC），不用架伺服器，丟 GitHub Pages 就能跟朋友玩。

## 本機跑起來

ES module 不能用 `file://` 直接開，要起一個靜態伺服器：

```bash
cd rust-duel
npm start          # = npx serve -l 8080 .
```

開 http://localhost:8080 。單人練習模式可以直接玩；雙人要開兩個瀏覽器視窗，或丟給朋友。

## 怎麼連線

1. 在大廳上方選「對決」或「生存」（以房主選的為準）
2. 一個人按「建立房間」，拿到 6 碼房間碼（或按「複製邀請連結」）
3. 另一個人輸入房間碼按「加入」，或直接開邀請連結
4. 連上就自動開打

### TURN（選用）

預設只用 Google 的公開 STUN。同一個 Wi-Fi、一般家用網路通常這樣就夠了，
但如果有人用手機行動網路（電信級 NAT），可能會卡在連線中。

要開 TURN 的話：把 `js/turn-config.example.js` 複製成 `js/turn-config.js`，填入帳密。
戰艦專案 `battleship/js/net.js` 裡的 `ICE_CONFIG` 可以整段照搬。
有這個檔案，遊戲就會自動使用；沒有的話，大廳會跳提示。

> 放上 GitHub Pages 之後，`turn-config.js` 是公開的，誰都看得到帳密（跟戰艦專案現在的狀況一樣）。
> 如果不想公開，就把它加進 `.gitignore`，只在本機用。

## 手機版

偵測到觸控裝置（或網址加 `?touch=1`）就會自動切成手機模式：

- **操作**：左半邊按哪裡哪裡就是搖桿中心，推到底往前就是衝刺；右半邊拖曳轉視角。右下是固定位置的按鈕：開火、瞄準、跳、蹲、換彈。左手拇指上方還有第二顆開火鍵。快捷欄第 2 格點一下就打針筒，左上 ❚❚ 是暫停
- **開火鍵按住時手指拖曳也會轉視角**，這樣才壓得了槍
- **輔助瞄準（只給手機）**：準心靠近對手時視角轉速減半；開鏡或開火時再往身上吸。垂直方向只吸一半，後座力還是要自己壓。隔著牆不會吸
- **自動降畫質**：解析度倍率最多 1.25、陰影貼圖 1024、草 4500 叢、霧濃一點
- 點「開始」時會嘗試切全螢幕並鎖橫向。iPhone Safari 不支援，直接橫著拿就好，直著拿會跳出提示

手機走行動網路時通常需要 TURN，請參考上面的 TURN 段落。

## 石頭、木頭、木牆

- 每個人開局都有一顆**石頭**（快捷欄 3）。對著樹敲一下拿 25 木頭，一棵樹 200 木頭，敲完會倒下去
- 石頭也能敲人：身體 20、爆頭 32
- **木牆**（快捷欄 4）：100 木頭一面，會蓋在面前 2.6 公尺、朝向跟著視角轉。綠色預覽是可以蓋，紅色是不行（地太斜、擋到東西、會卡到人、木頭不夠）。每人最多 8 面
- 木牆擋得住子彈，耐久 350：AK 一發扣 10（要 35 發），石頭一下扣 25。準心對著牆會顯示剩多少
- 死掉的時候身上的木頭會全掉光（rust 傳統），蓋好的牆會留著
- 牆、樹的狀態雙方會同步：誰出手誰算，再廣播給對方

## 生存模式

開局兩個人都在海灘醒來，身上只有一顆石頭。限時 30 分鐘，時間到時擊殺多的人贏，一樣就平手。

- **死掉時身上所有東西包成一個背包掉在原地**，雙方都能按 E 搜刮（沒人撿 5 分鐘後消失）。被自己的手雷炸死、被北極熊咬死、餓死，都不算對手的分
- **飢餓度**（最多 500）：每秒掉 0.18，衝刺再多掉 0.18；歸零後每秒扣 0.5 血、也不會自己回血。出生時 120～170
- 沒有針筒：12 秒沒受傷、而且沒在餓肚子，就開始每秒回 1 血
- 有放睡袋就能從睡袋重生（冷卻 15 秒），不然是海灘（3 秒）
- 槍要自己做子彈：AK47 用步槍子彈、湯姆森用手槍子彈。剛做好的槍彈匣是空的，按 R 換彈從背包拿；背包裡點槍可以退出子彈

### 雪地、北極熊、吃東西

- 地圖往北多了一大片雪地（z −56 到 −118），從超市後面的小徑穿過山口過去。會下雪、霧比較白、風聲比較大，有雪地營地、比較多礦點和鐵桶
- **北極熊**：240 血，一爪 18（冷卻 1.4 秒），16 公尺內看到人就衝過來；跑速 6.3（玩家走路 4.6、衝刺 6.9），離開雪地就不追。爆頭 ×1.5、腿 ×0.8。最多 3 隻，死掉 90 秒後在雪地別處再生
- 吃東西：生熊肉飢餓 +20、扣 6 血（會吐）；烤熊肉飢餓 +100、慢慢回 20 血；繃帶馬上 +15、慢慢再 +10

## 美術方向

照 Steam 商店頁上 rust 的 33 張官方截圖抓特徵，盡量用程式碼重現：

- **天空與光線**：晴天藍天、大朵積雲（亮白頂部、藍灰底部）、從南邊斜照的強烈陽光。天空烘成環境貼圖，金屬和水面會反射天空
- **空氣透視**：遠景往淡藍白色淡出；地圖外圍一圈遠山長滿針葉林，南邊是海
- **後製**（暫停選單可以關）：泛光、太陽方向的螢幕空間光束、輕微 S 曲線對比、暗部偏冷藍亮部偏暖黃、暗角、底片顆粒
- **植被**：又高又密的黃綠色草和一小片一小片的野花、雲杉、秋天黃橘色的樺樹、櫸樹、枯樹、倒木、蕨類，部分灌木轉紅

- **中央地標**：「S PERM KET」超市（SUPERMARKET 掉了 U、A、R），綠色腰板、白牆、紅色招牌帶，前面有停車場、水泥護欄、交通錐、廢車

- **地圖邊緣**：一層一層的淺灰色石灰岩壁
- **HUD**：右下血量／水分／食物（數字在色條裡），撿東西的通知是綠色長條

## 網路架構

- 判定是「開槍的人判」：射手自己做射線檢測，打中就送 `hit` 給對方；對方扣血，死了回傳 `dead`，射手才加分
- 位置每秒送 20 次，對方畫面延遲 110ms 做內插，換取不抖
- 雙方各自計分：自己的擊殺數 = 收到幾次 `dead`，對手的擊殺數 = 自己被對手殺了幾次
- 生存模式的訊息都包在 `{ t: 'sv', k: ... }` 裡：
  - 自己做的事（蓋、挖、打鐵桶、丟手雷）自己算，再廣播給對方套用同樣的結果
  - 「容器」（地上的東西、死掉的背包、火爐）只有房主能改：客人送 `cop` 請求，房主改完廣播 `cset`、回 `cgive` 給客人，兩個人同時搶同一件東西也不會變成兩件
  - 鐵桶刷新、礦點重生、火爐冶煉都由房主決定；單人模式自己就是房主
  - 北極熊由房主跑 AI，每秒送 8 次位置；客人打中熊送 `bdmg` 給房主扣血，熊咬到客人時房主送 `hit`（帶 `env`，不算對手的分）
